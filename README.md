# Coastal-flood-exposure-Lagos-Mombasa
Comparative compound-flood and critical-infrastructure exposure framework for Lagos and Mombasa. Uses Sentinel-1 InSAR subsidence, IPCC AR6 SSP2-4.5/5-8.5 sea-level rise (2030/2050/2100), an enhanced CVI, LISFLOOD-FP modelling on FABDEM, and GeoPandas/Rasterio exposure analysis with OSM, building footprints and WorldPop.
